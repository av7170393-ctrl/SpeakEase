# 🎙️ SpeakEase – Interview English Coach

A speech-enabled web app to practise **interview-level spoken English** at three CEFR levels (A1–A2, B1–B2, C1–C2) with kind, non-judgmental feedback.

## Features
- 3 levels with interview questions and level-wise hints
- Speak (Web Speech API) or type your answer; listen to the question aloud
- Growth score out of 100 (Fluency, Vocabulary, Grammar, Detail & structure)
- Friendly feedback: strengths, gentle tips, grammar buddy
- Live stats: words, time, words per minute, filler words
- Progress chart saved on your device (localStorage)

## Tech
HTML, CSS, JavaScript (vanilla), Web Speech API (speech recognition + synthesis), SVG charts.

## Run locally
Open `index.html` in **Google Chrome** (best support for voice). No installation needed.
